# Безопасность учётных записей в соцсетях

Интерактивный веб-ресурс с практическими рекомендациями по настройке безопасности для **ВКонтакте, Telegram и МАХ**.  
Включает пошаговые инструкции, интерактивные чек-листы, тестер надёжности пароля и встроенную админ-панель для управления контентом.

**Демо:** [effectgth.github.io](https://effectgth.github.io)

---

## О проекте

Проект создан для студентов и всех, кто хочет быстро и понятно настроить защиту своих аккаунтов.  
Основные разделы сайта:

- Рекомендации по созданию надёжных паролей
- Включение двухфакторной аутентификации (2FA)
- Настройка приватности профиля
- Обзор мошеннических схем
- Инструкции при взломе аккаунта

Каждая страница содержит интерактивные чек-листы с сохранением прогресса, а страница паролей — тестер сложности в реальном времени.

---

## Быстрый старт

Клонируйте репозиторий и откройте `index.html` в браузере:

```bash
git clone https://github.com/EffectGTH/EffectGTH.github.io.git
cd EffectGTH.github.io
# открыть index.html
```

> Для работы админ-панели требуется подключение к интернету (GitHub API).

## Админ-панель (CMS)

Админ-панель позволяет управлять статьями без знания Git и HTML-вёрстки.

- **Вход:** `/admin/login.html`  
- **Пароль по умолчанию:** `admin2024` (можно изменить в коде)
- **Требуется GitHub Personal Access Token** с правами `repo` (вводится при первом входе)

Возможности:

- Просмотр списка всех статей
- Редактирование HTML-кода любой статьи
- Создание новой статьи (с шаблоном)
- Удаление статьи
- Медиатека – загрузка изображений и копирование ссылок

---

## Добавление новой статьи

1. Создайте HTML-файл в папке `articles/`
2. Обязательно укажите `<title>` – он будет использован как название в меню
3. Поместите контент внутри блока `<div class="editable-content">` – так админ-панель сможет его редактировать
4. Запустите генератор навигации:
   ```bash
   node scripts/generate-json.js
   ```
   или дождитесь автоматического запуска через GitHub Actions (при пуше в ветку `main`)
